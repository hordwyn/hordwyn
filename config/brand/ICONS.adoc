= Vendored icons, logos and fonts

Every icon, logo or font file shipped with the application is listed here with its source and
licence (KICKOFF rule 11, DESIGN D-10). The research behind the choice is in
`docs/research/icons.md`; the decision is DEC-043.

== UI icons

Vendored under `src/rust/crates/ui/icons/vendor/`. Only the icons named in
`src/rust/crates/ui/icons/icons.toml` are copied and compiled in. The licence files sit next
to the icons and are copied into the Docker image (`/usr/share/doc/app/icons`). From 1.0.1 the
image also carries `/usr/share/doc/app/THIRD-PARTY-NOTICES.txt`, generated at build time by
`src/sh/notices.sh`: the notices of every Rust crate (cargo-about), these icon licences, the
font licences and the Tailwind CSS licence (DEC-855).

Neither licence requires per-use attribution; keeping the licence texts with the files and in
the image satisfies them.

== Service logos

None vendored yet. Until they are, integrations and data sources are identified by name
(text) only. When added, they come from Simple Icons (CC0-1.0) and, for gaps, selfh.st/icons
(CC-BY-4.0, credit on the About page), are shown only to identify the service, and are listed
here.

== Fonts

Vendored under `config/brand/default/fonts/` and served by the application from its own
origin (`/brand/fonts/...`, never a CDN; design.md 2.8, DEC-171). The licence text sits next
to the files, unaltered, as `fonts/OFL.txt`, and is copied into the Docker image with the
brand directory (`/etc/app/brand/default/fonts/OFL.txt`).

The OFL allows bundling and redistribution with software, including commercial, as long as
the licence and copyright notice travel with the font and the font is not sold by itself.
Take the files from the googlefonts repository only: the Braille Institute download is under
its own EULA (design.md 2.8). The open-source attribution page (owner ruling R-F3) lists this
font.

== Brand logo

The default brand (`config/brand/default/`) uses the product name set as text; no drawn or
generated mark. Third-party icon files never go into the brand logo slots.
