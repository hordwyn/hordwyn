== Test results

* `cd src/rust && cargo xtask ci`: fmt, clippy pedantic (native and wasm32), cargo-deny,
  sqlx offline cache, all tests against local Postgres, Meilisearch and versitygw (S3),
  wasm tests. Last green run: the commit of tag `m13`; 249 tests passed, 0 failed, 2 ignored
  (live provider smoke tests), no service-dependent test skipped.
* `cargo xtask e2e`: 12 Playwright tests green (8 gallery/accessibility tests with axe
  WCAG A/AA, the M07 slice test with the TMDB fixture server, 2 M15 sharing tests, 1 M13
  notifications test).
* Latency (M05 acceptance, `apps/server/tests/latency.rs`): with a connector that takes 10 s,
  item detail 3-5 ms, search 1-2 ms (limit 200 ms); `entity.updated` after 10.2 s,
  `search.results` after 10.0 s.
* Storage budget property tests (eviction never removes pinned objects, always ends at or
  below the low watermark) and mutation checks (removing the pinned filter or the hard cap
  makes them fail).
* Search suite: the same tests pass for Meilisearch 1.56 and the Postgres fallback; a
  mutation check (dropping the owner filter) makes the tenant test fail.
* GitLab: pipelines run on every push; the earlier run never had a fully green pipeline
  (Docker build and cache problems, fixed here). Docker image size not yet measured.
* Coverage: not measured.

== Most important decisions

. DEC-050/051: continue on the earlier run's history; reviews and research done by this
  session on the owner's instruction.
. DEC-106: four mandated connectors are GPL-family services; their docs were not read.
. DEC-108: AniList's terms forbid tracker apps; not implemented.
. DEC-054/058/059: storage accounting in `stored_objects`, weighted LRU, per-process
  admission.
. DEC-067..072: auth design (session hashes, argon2 on the blocking pool, TOTP replay
  protection, OIDC through the governed client).
. DEC-084/085: Meilisearch master key only at start-up, adapters enforce tenant filters.
. DEC-090: Fluent instead of leptos_i18n (runtime brand overrides).
. DEC-092: server functions over a `Backend` trait, sharing `api::ops` with REST.
. DEC-055/091: lean dev profile; the 20 GB build host filled up three times.
. DEC-114/109/079: bugs found by end-to-end tests in earlier code.
