= Overview

A self-hosted, multi-user, white-label tracker for media of many kinds
(movies, shows, anime, manga, books, audiobooks, podcasts, music, video games,
visual novels, comics and board games).

The docs use the name of the default brand, Hordwyn (Old English _hordwynn_, "joy of the
hoard"); deployments set their own name through the brand configuration (see the
white-labelling guide).
