= Connectors and attribution

Each connector is compiled in behind a cargo feature and can be turned off per deployment
(`connectors.<id>.enabled = false`). Its `ConnectorInfo` carries the attribution shown on
item pages (for the connectors that supplied the item) and on the "Data sources" page.
Before a connector is implemented, its API terms, licence, attribution, auth and rate limits
are recorded in `docs/connectors/<id>.md`.

== The operator contact

Some sources ask every client to say who runs it. The instance setting
`instance.operator_contact` holds that: an e-mail address (preferred: the sources name an
e-mail address, and Open Library gives its higher rate for one) or an https URL, at most
200 characters. An admin sets it on Admin > Data sources; `KK_OPERATOR_CONTACT` (or
`APP__INSTANCE__OPERATOR_CONTACT`) in the environment sets it for good and the page then
shows it read-only. It is the operator's contact, never a member's.

A connector declares whether it gets the contact: `none` (TMDB, TheTVDB, IGDB, Podcast
Index: their requests carry the plain application `User-Agent` and never the contact),
`preferred` (Open Library: asked with and without it) or `required` (a source that is not
asked at all without one; its state on the sources page and in the search footer is
"Operator contact missing"). The header of a source that gets it is
`<brand ident>/<version> (<contact>)`. It goes with a request also where the source
redirects it (a cover of Open Library is served by `archive.org` hosts). A worker that runs
as its own process reads the contact when it starts: restart it after the contact was
changed or removed.

A source without a key counts the requests of an address, whichever process sent them. The
web role, a separate worker and the commands of the admin tool therefore take turns at such
a source from one pace in the database (table `source_pace`), so the instance as a whole
stays inside the rate the connector declares.

== Data licences

Provider data and images keep their own licences. Open data licences (for example ODbL or
CC BY-SA) do not change this project's MIT licence, but may require attribution, which is
why every connector declares its attribution text, URL and licence.

== Network rules

Connectors never open connections themselves: every request goes through the governed HTTP
client (host allowlist, rate limit, circuit breaker, cache), see
xref:provider-pipeline.adoc[provider pipeline]. The project never talks to indexers,
trackers, Prowlarr/Jackett, torrent or usenet clients, and never searches for or handles
media files.
