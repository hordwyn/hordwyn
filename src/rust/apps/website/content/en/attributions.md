Every instance of {name} carries its own credits page with the exact notices of the sources it has switched on. This page names what the project as a whole builds on.

## Data sources of the application

- **[TMDB](https://www.themoviedb.org)** - movies and shows. This product uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.
- **[TheTVDB](https://thetvdb.com/)** - shows, with the operator's own key. Metadata provided by TheTVDB. Please consider adding missing information or subscribing.
- **[IGDB](https://www.igdb.com/)** - video game data from IGDB.com.
- **[Podcast Index](https://podcastindex.org/)** - podcast data from the Podcast Index.

- **[Open Library](https://openlibrary.org/)** - book data and covers from Open Library.

Names and marks of these services belong to their owners and are used only to name the service. This website itself shows no data from them.
